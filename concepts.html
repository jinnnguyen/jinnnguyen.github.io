Key Concepts

Core terminology and foundational principles behind PWAs

Overview of Concepts

Below is a summary table outlining 6 essential concepts central to Progressive Web Applications:

Concept Definition / Description
1. Service Workers Programmable network proxies that handle background caching and offline functionality.
2. Web App Manifest JSON configuration file that defines how the app appears to the user system.
3. App Shell Architecture The minimal HTML, CSS, and JavaScript UI framework required to load the app layout.
4. HTTPS Security Encrypted connection layer required for browser trust and feature authorization.
5. Responsiveness Flexible layouts that adapt smoothly across mobile, tablet, and desktop screens.
6. Push Notifications Server-sent alerts that re-engage users even when the browser window is closed.
